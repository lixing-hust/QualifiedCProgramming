# Build instructions

The order of building files is recorded in `_CoqProject`. Changes to this file should be pushed to the remote repository.

To produce make file from `CoqProject`, use:

```bash
coq_makefile -f _CoqProject -o CoqMakefile
```

To make, use:

```bash
make -f CoqMakefile
```

## Building in the existing Coq 8.15.2 opam environment

From this directory, use the `osverify-coq815` switch and a serial build on
memory-constrained WSL instances:

```bash
OCAMLRUNPARAM='s=32M,o=20' opam exec --switch=osverify-coq815 -- \
  make -f CoqMakefile -j1
```

Setting `OCAMLRUNPARAM` bypasses Coq's default GC configuration. `s=32M`
preserves its 32M-word minor heap (256 MiB on this 64-bit environment), while
`o=20` reduces major-heap space overhead. Setting only `o` also loses the enlarged
minor heap and can make these proofs much slower.

The long proofs in `CNodeDelRecProof.v` and `IntExitProof.v` include periodic
`Optimize Proof.` / `Optimize Heap.` checkpoints to discard solved existential
variable records and compact the heap. These commands do not skip proof checking
or change the theorem statements. Successful compilation still requires `Qed`.

(if MinGW on Windows is used, name of the `make` program may be `mingw32-make`, etc)

On Windows, it is also necessary to manually remove the following lines from `CoqMakefile` after each change to `_CoqProject` (lines 409-413):

```make
@# Extension point
$(HIDE)if [ "$(COQMAKEFILE_VERSION)" != "$(COQ_VERSION)" ]; then\
  echo "W: This Makefile was generated by Coq $(COQMAKEFILE_VERSION)";\
  echo "W: while the current Coq version is $(COQ_VERSION)";\
fi
```
